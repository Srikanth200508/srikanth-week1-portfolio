# Srikanth Madari — Week 1 Portfolio

This project completes the Week 1 Personal Portfolio assignment using:
- HTML5 semantic structure
- CSS3
- Flexbox
- CSS Grid
- Responsive design
- JavaScript ES6-style functions and DOM events
- JavaScript form validation

## Resume-based sections
- About
- Education
- Technical Skills
- Projects
- Contact

## Files

- index.html — portfolio structure
- style.css — styling, Flexbox, Grid, responsive design
- script.js — mobile menu and contact form validation

## How to run

1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.

Recommended VS Code extension:
- Live Server

With Live Server:
1. Right-click `index.html`
2. Select "Open with Live Server"
